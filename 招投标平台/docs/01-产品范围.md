# MVP 产品范围

## 定位

电子招投标 Web 平台雏形，用于学习与内部演示。不宣称具备法定交易资格。

## MVP 内（必须）

1. 三角色：平台管理员 `admin`、招标人 `buyer`、投标人 `bidder`
2. 管理员开户（创建招标人/投标人账号）
3. 招标人：创建项目 → 填写公告/截止时间/评分办法 → 上传招标文件 → 发布
4. 投标人：浏览已发布项目 → 提交投标文件 → 截止前撤回重传
5. 截止后禁止新投标（访问时惰性推进状态）
6. 招标人：开标（不可变快照）→ 录入评分/选定中标 → 发布公示
7. 投标人：查看公示与是否中标

## MVP 外（明确不做）

- 电子签章 / CA / 国密
- 保证金支付
- 多轮澄清自动流程
- 专家库抽取与回避
- 加密投标文件
- 可配置工作流 / BPM
- AI 写标（Phase 2）
- 完整等保审计

## Phase 2 预留

- 评委角色与多评委打分
- 澄清答疑、补遗版本
- 投标端 AI 写标插件
