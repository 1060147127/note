# 演示脚本

## 前置

```bash
cd 招投标平台/apps/web
npm install
npm run setup
npm run dev
```

打开 http://localhost:3000

## 端到端路径

1. **admin** 登录 → 用户管理确认账号存在（或新建一个投标人）。
2. **buyer** 登录 → 新建项目「演示办公设备采购」→ 填截止时间（可设为数分钟后）→ 上传招标 PDF/任意文件 → 发布。
3. **bidder1** 登录 → 项目大厅看到项目 → 上传投标文件并提交。
4. **bidder2** 登录 → 同样提交一份投标。
5. 等待截止，或用管理/招标端刷新项目（惰性推进为已截止）；也可在种子里预置已截止项目。
6. **buyer** → 开标 → 看到两份投标快照 → 录入分数并勾选中标人 → 定标 → 填写公示内容并发布。
7. **bidder1/2** → 查看公示与中标结果。
