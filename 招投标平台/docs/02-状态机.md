# 项目状态机

## 状态枚举

| 状态 | 含义 |
|---|---|
| `DRAFT` | 草稿，仅招标人可见可编辑 |
| `PUBLISHED` | 已发布（与 BIDDING 等价入口，发布即进入投标） |
| `BIDDING` | 投标进行中 |
| `CLOSED` | 已截止，禁止新投标 |
| `OPENED` | 已开标，快照已固化 |
| `EVALUATING` | 评标中 |
| `AWARDED` | 已定标 |
| `ANNOUNCED` | 已公示 |

## 流转

```
DRAFT → BIDDING（发布时直接进入投标中）
BIDDING → CLOSED（截止时间到达，惰性推进）
CLOSED → OPENED（招标人开标）
OPENED → EVALUATING（开始录入评分）
EVALUATING → AWARDED（选定中标人）
AWARDED → ANNOUNCED（发布公示）
```

说明：`PUBLISHED` 在数据层可与 `BIDDING` 合并；本实现发布后状态为 `BIDDING`。

## 谁可操作

| 操作 | 允许角色 | 前置状态 |
|---|---|---|
| 创建/编辑项目 | buyer（本人） | DRAFT |
| 上传招标文件 | buyer（本人） | DRAFT |
| 发布 | buyer（本人） | DRAFT（需有截止时间与至少 1 个招标文件） |
| 提交/撤回投标 | bidder | BIDDING 且未过截止 |
| 开标 | buyer（本人） | CLOSED |
| 录入评分/定标 | buyer（本人） | OPENED / EVALUATING |
| 发布公示 | buyer（本人） | AWARDED |
| 查看公示 | 全登录用户 / 投标人 | ANNOUNCED |
| 开户 | admin | — |

## 惰性推进

任何读取项目详情/列表时：若 `status === BIDDING` 且 `now >= bidDeadline`，则自动改为 `CLOSED`。
